# 路演演示脚本

> 对应课程第 3 天（9 月 9 日）核心产出
> 文档版本：V1.0 ｜ 编制日期：2026-09-09 ｜ 设计人：唐晶

## 0. 演示准备

- 环境：本机开发环境（PC 端 :5173、后台 :5174）或容器环境（:8081 / :8082），二选一
- 测试账号（种子数据）：游客 13800000001 / 密码 123456；管理员 admin / 123456（以 02-dml.sql 实际数据为准）
- 提前打开的页面：PC 首页、管理后台登录页（另开标签页备用）
- 时间控制：全场 6-8 分钟，每个环节标注了参考用时

## 1. 开场与首页（30 秒）

- 打开 PC 端首页：轮播图、活动横幅、公告、热门商品/民宿/路线/帖子推荐位
- 口播：首页数据由 Redis 缓存聚合（key home:data），运营配置变更自动失效

## 2. 注册登录（30 秒）

- 注册新游客账号：输入手机号，验证码固定 123456（口播：模拟短信，生产接真实服务）
- 登录后观察导航栏昵称；可顺带演示个人中心资料修改

## 3. 衣——非遗商品（1 分钟）

- 进入非遗商品：分类树（银饰/蜡染等，一级含二级）、关键词搜索、价格区间筛选、销量排序
- 打开商品详情：SKU 规格、商品图片、传承人介绍、已有评价（口播：详情页有 Redis 缓存）
- 收藏商品；发表一条评价
- 选规格加入购物车

## 4. 食——餐饮与特产（45 秒）

- 进入餐饮页：餐厅列表（按名称/地址搜索）
- 餐厅详情：菜品、用餐时段与当日余量（满员状态展示）
- 预订明日餐位：人数、联系信息提交（口播：餐位预订生成 0 元订单，含余量预扣）
- 农产品：浏览特产加入购物车

## 5. 住——住宿预订（45 秒）

- 民宿列表：风格标签/关键词/最低价区间筛选
- 民宿详情：房型与 30 天房态日历（满房日期不可选）
- 选择房型与日期：动态房价计算（多晚合计）
- 提交预订：入住人信息（口播：生成待支付订单并预扣逐日房态，入住码 6 位数字）

## 6. 行——门票与路线（1 分钟）

- 景区列表与票种：选择日期查看余票（total - sold 实时计算）
- 购买门票：数量、游客信息
- 路线列表：天数/主题筛选；路线详情逐日行程
- 购买路线套餐：选择出行日期（口播：须提前 1 天预订）
- 支付后查看"我的电子票"：逐张生成的票码；模拟商家核销（在后台或用核销接口）展示核销后状态

## 7. 购物车与统一结算（45 秒）

- 打开购物车：非遗商品 + 农产品混合展示
- 全选结算：系统自动拆单（不同商家分单）
- 提交订单进入待支付

## 8. 订单中心与模拟支付（45 秒）

- 订单列表：多类型订单标签、状态流转
- 对待支付订单发起支付：模拟微信支付二维码页面 → 点击"模拟扫码支付"
- 观察状态变化：已支付；商家端佣金记账同步产生（口播，不展开）
- 演示一笔退款：申请退款 → 后台审核通过 → 状态已退款、库存回补

## 9. 社区（45 秒）

- 发布一篇游记（配图）：正常过审
- 演示敏感词拦截：内容含敏感词时转人工审核，个人主页状态显示"审核中"
- 浏览热门帖子：点赞、评论、收藏、关注作者

## 10. 管理后台（1 分钟，切换标签页）

- 平台管理员视角：
  - 数据看板：GMV、订单量、用户数（口播：只统计有效订单）
  - 用户管理：封禁/解封操作
  - 内容审核：过审刚才的敏感词帖子
  - 入驻审核：审核商家申请（角色自动升级）
  - 结算管理：查看已生成的 T+7 结算单
- 商家视角（可选，切换账号）：
  - 订单管理：查看订单、餐位预订确认/拒绝、电子票核销
  - 商品/民宿/路线等经营数据管理

## 11. 技术交付展示（30 秒，可选）

- Swagger 接口文档页（:7001/swagger-ui）：接口全量在线可测
- 单元测试：`cd server && npm test` 屏幕展示 227 用例全绿 + 覆盖率报告
- Docker：`docker compose ps` 展示五个容器健康状态

## 12. 收尾（15 秒）

- 口播：演示覆盖衣、食、住、行、社区、平台管理六大模块与完整交易闭环；系统代码、测试、部署一键可复现；请老师提问。

## 风险预案

| 风险 | 预案 |
| --- | --- |
| 某接口报错 | 口播"该功能有 227 个用例保障，此路径已覆盖"，切到下一环节，不中断演示 |
| 演示环境服务没启动 | 开场前检查三个端口；若后端挂了，10 秒内 `npm run dev` 拉起 |
| 种子数据被演示过程改动 | 演示前 `docker compose down -v && up -d`（容器环境）或重新导入 DML 重置 |
| 网络/浏览器卡顿 | 提前打开所有演示页面标签页；关键操作步骤写在本脚本上照稿操作 |
