## 一、运行环境与访问方式

### 1.1 访问地址

| 端 | 开发环境（npm run dev） | 容器部署（docker compose） |
|------|------|------|
| PC 游客端 | http://localhost:5173 | http://localhost:8081 |
| 管理后台 | http://localhost:5174 | http://localhost:8082 |

后端服务开发环境为 http://localhost:7001，容器部署时与 PC 端、管理后台一并由 deploy/docker-compose.yml 编排启动。

### 1.2 演示账号

| 角色 | 手机号 | 密码 | 说明 |
|------|------|------|------|
| 游客 | 13800000001 | user123 | PC 游客端登录 |
| 商家（衣） | 13800000002 | merchant123 | 可登录 PC 端与管理后台 |
| 食商家 | 13800000003 | merchant123 | 管理后台演示 |
| 住商家 | 13800000004 | merchant123 | 管理后台演示 |
| 行商家 | 13800000005 | merchant123 | 管理后台演示 |
| 平台管理员 | 13800000000 | admin123 | 管理后台登录 |

说明：商家账号同时具备 PC 游客端权限（可浏览、下单）；平台管理员账号登录管理后台后拥有全部管理菜单。

### 1.3 访问前准备

1. 后端服务已启动（开发环境为 server 目录的 Midway 服务，容器环境为 wudong-server 容器）。
2. MySQL（wudong 库）与 Redis 已就绪，数据库已执行 sql/01-ddl.sql 与 sql/02-dml.sql 种子脚本。
3. 浏览器建议使用 Chrome 或 Edge 最新版。

## 二、PC 游客端操作流程

游客端顶部导航包含：首页、非遗好物、苗乡美食、民宿住宿、景区出行、社区分享；右侧为购物车、我的订单、个人中心（未登录时显示登录、注册入口）。

### 2.1 注册与登录

#### 注册

1. 点击顶部导航右侧「注册」，进入注册页。
2. 填写手机号（11 位，以 1 开头）。
3. 点击「获取验证码」，页面提示"验证码已发送（测试环境为 123456）"，按钮进入 60 秒倒计时。
4. 在「短信验证码」输入框填写 123456（测试环境固定值，见 5.1）。
5. 填写昵称、密码（至少 6 位）、确认密码。
6. 点击「注册」，成功后自动跳转登录页。

#### 登录

1. 点击顶部导航「登录」或从注册页点击「已有账号，去登录」。
2. 输入手机号与密码，点击「登录」。
3. 登录成功后返回首页；若因访问受保护页面被拦截，登录后会自动跳回原页面。

#### 退出登录

1. 点击顶部导航右侧昵称展开下拉菜单。
2. 选择「退出登录」，回到首页。

### 2.2 首页浏览

1. 访问首页 http://localhost:5173/。
2. 页面自上而下依次为：轮播图、平台公告、活动横幅、「热门非遗好物」「热门民宿」「热门路线」「社区热帖」四个推荐区。
3. 点击商品卡片进入商品详情；点击民宿卡片进入民宿详情；点击路线卡片进入路线详情；点击热帖进入帖子详情。

### 2.3 非遗商品（衣）

#### 商品列表

1. 点击顶部导航「非遗好物」进入商品列表。
2. 左侧为分类树，点击一级分类后上方出现二级分类标签，再次点击可选中或取消该二级分类。
3. 顶部搜索框输入关键词后点击「搜索」或按回车，可按商品名搜索。
4. 右侧排序按钮支持：综合、销量、价格升序、价格降序。
5. 列表每页 12 件，底部翻页；点击商品卡片进入详情页。

#### 商品详情与购买

1. 详情页展示：主图、标题、副标题、售价与市场价、已售与评分、工艺介绍。
2. 若商品有多个 SKU 规格，点击规格标签选择（标签上显示各规格库存）。
3. 在「数量」处设置购买数量（1 至 99）。
4. 点击「加入购物车」将商品放入购物车；未登录时会提示先登录。
5. 点击「收藏」收藏商品，再次点击取消收藏（按钮文案在「收藏」与「已收藏」间切换）。

#### 商品评价

1. 页面下方「用户评价」区域展示全部评价（昵称、星级、时间、内容、追评）。
2. 登录后可在评价表单中选择星级（1 至 5 星），填写体验内容（500 字以内），点击「发表评价」。
3. 未登录时显示"登录后可发表评价"。

### 2.4 餐饮（食）

#### 餐厅列表

1. 点击顶部导航「苗乡美食」进入餐饮页，默认显示「苗乡餐厅 · 餐位预订」标签页。
2. 搜索框可按餐厅名搜索；排序支持「评分优先」「容纳人数」。
3. 列表展示餐厅图片、名称、介绍、评分与可容纳人数；点击卡片进入餐厅详情。

#### 餐位预订

1. 在餐厅详情页查看地址、营业时间、评分、容纳人数与介绍，以及「招牌菜品」区。
2. 在「餐位预订」表单中操作：
   1. 选择「预订日期」（不能选过去日期，切换日期会刷新各时段余量）。
   2. 在「用餐时段」单选组中选择时段，每个时段显示剩余可订数。
   3. 设置「用餐人数」（1 至 20）。
   4. 填写「联系人」与「联系电话」。
3. 点击「提交预订（免费，需提前 2 小时）」完成预订，成功后跳转到我的订单页查看。
4. 餐位预订为免费预订，商家在管理后台确认后订单状态更新为已确认。

#### 苗乡特产（农产品）

1. 切换到「苗乡特产 · 农产品」标签页。
2. 顶部下拉框可按特产分类筛选，搜索框可按名称搜索。
3. 卡片上点击「加购物车」可直接加入；点击卡片弹出详情弹窗，展示产地溯源、保质期、介绍，可调整数量后点击「加入购物车」。

### 2.5 住宿（住）

#### 民宿列表

1. 点击顶部导航「民宿住宿」进入民宿列表。
2. 搜索框支持按民宿名称或地址搜索。
3. 「价格」处填写最低价与最高价后点击「筛选」，可按价格区间过滤。
4. 排序支持「评分优先」「价格升序」；卡片展示图片、名称、地址、风格标签、起价与评分。

#### 民宿详情与预订

1. 点击民宿卡片进入详情页，查看地址、入住与离店时间、评分、是否含早餐、是否允许宠物、押金金额、风格标签与介绍。
2. 在「房型选择」区点击房型卡片选中房型（显示床型、面积、可住人数、设施与每晚价格）。
3. 在「预订信息」表单中操作：
   1. 选择「入住日期」区间（日期范围选择器，不能选过去日期）。
   2. 系统自动显示逐晚价格明细与「共 X 晚，合计金额」。
   3. 填写「入住人」「身份证号」「联系电话」。
4. 点击「提交预订并支付」，生成住宿订单并跳转收银台（见 2.10）。

### 2.6 出行（行）

#### 景区门票

1. 点击顶部导航「景区出行」进入景区页。
2. 每个景区卡片展示名称、地址、开放时间、介绍，以及「票种」列表（票名、有效期规则、价格）。
3. 在每个票种右侧：
   1. 选择「使用日期」（不能选过去日期，切换日期后购买按钮上的余票数实时刷新）。
   2. 设置购买数量（1 至 10）。
   3. 可填写「游客姓名」（多个姓名用逗号分隔，选填）。
4. 点击「购买（余 X）」生成门票订单并跳转收银台；当日余票不足时无法购买。

#### 旅游路线

1. 点击「景区出行」导航内或在首页点击热门路线进入「路线」列表。
2. 搜索框可按路线名称搜索；下拉框可按天数筛选（1 日游、2 日游、3 日游）。
3. 路线卡片展示出发地、目的地、天数、主题标签、价格与已售数量。
4. 点击卡片进入路线详情：
   1. 查看出发地、目的地、天数、住宿与用餐标准、费用包含、注意事项。
   2. 「行程安排」区以时间线形式展示逐日行程（景点、用餐、住宿、交通）。
   3. 在「预订出发」表单中选择出发日期（最早明天）、出行人数（1 至 20），可填写游客姓名（逗号分隔，选填），页面实时显示合计金额。
   4. 点击「提交订单」生成路线订单并跳转收银台。

#### 出行攻略

1. 在出行模块进入「攻略」列表，顶部下拉框可按出发地筛选。
2. 卡片展示出发地到目的地、交通方式、用时、费用；点击卡片弹出详情弹窗查看完整攻略内容。

#### 我的电子票

1. 顶部导航昵称下拉菜单中选择「我的电子票」。
2. 列表展示门票与路线套餐两类电子票：票号、游客、使用日期、状态（未核销、已核销、已退款）与核销时间。
3. 电子票由商家在管理后台扫码核销，游客凭票号入园或参加行程。

### 2.7 社区

#### 浏览与筛选

1. 点击顶部导航「社区分享」进入社区。
2. 顶部话题标签可筛选指定话题，再次点击取消。
3. 列表上方可切换「最新」「热门」「关注」三个标签页；「关注」需登录后查看。
4. 帖子列表展示标题、摘要、作者、时间、赞、评论与浏览数；点击进入帖子详情。

#### 发布游记

1. 点击社区页右上角「发布游记」（需登录）。
2. 填写标题（200 字以内）、选择话题（选填）、正文（5000 字以内）。
3. 「图片」区点击「+ 上传图片」上传图片：支持 jpg/png/webp，单张不超过 5MB，最多 9 张；点击图片右上角关闭图标可移除。
4. 「视频链接」可填写视频 URL（选填）。
5. 点击「发布」；若内容命中敏感词，系统提示"已提交人工审核，通过后可见"，否则直接发布成功。

#### 帖子互动

1. 详情页点击「点赞」为帖子点赞，再次点击取消。
2. 点击「收藏」收藏帖子，再次点击取消（按钮文案在「收藏」与「已收藏」间切换）。
3. 在作者卡片点击「+ 关注」关注作者，再次点击取消关注。
4. 「评论」区：
   1. 登录后在评论表单输入内容（500 字以内），点击「发表评论」。
   2. 每条评论下可点击「回复」，输入框自动带出"回复 @昵称："前缀；回复显示在原评论下方。
   3. 评论支持点赞（点击「赞 X」）；自己的评论可点击「删除」。
   4. 评论同样经过敏感词检测，命中后进入人工审核。
5. 点击「举报」弹出举报弹窗，填写举报原因后点击「提交举报」。

### 2.8 购物车与结算

1. 点击顶部导航「购物车」（带角标显示件数）进入购物车。
2. 勾选要结算的商品；「全选」只勾选有效且库存充足的商品。
3. 已失效商品标记「已失效」，库存不足商品标记「库存不足（仅剩 X）」且不可勾选。
4. 调整商品数量（自动限制在库存范围内）；点击「删除」并确认后移除商品。
5. 底部显示「已选 X 件，合计金额」，点击「结算」：
   1. 单个商家商品：直接跳转收银台支付。
   2. 多个商家商品：系统按商家拆分订单，提示"已按商家拆分为 N 个订单"并跳转订单页逐个支付。

### 2.9 订单中心与模拟支付

#### 我的订单

1. 点击顶部导航「我的订单」进入订单中心。
2. 标签页：全部、待支付、已支付、已确认、进行中、已完成、退款相关。
3. 每个订单展示：订单号、下单时间、状态、商品明细（含规格、单价与数量）、合计金额，以及扩展信息：
   1. 餐位预订：用餐日期、人数、联系人与电话。
   2. 住宿预订：入住至离店日期、晚数、入住人；订单已支付或已确认后显示红色「入住核销码」。
   3. 票务：门票或路线、使用日期、份数。
   4. 退款单：退款单号与状态（审核中、已退款、已驳回）及处理备注。
4. 订单操作按钮按状态显示：
   1. 待支付订单：「去支付」「取消订单」（确认后库存释放）。
   2. 已支付/已确认/进行中订单：「申请退款」，弹窗填写退款原因（默认"行程有变"）后提交，等待平台审核。
   3. 进行中的实物商品订单：「确认收货」，确认后订单完成。

#### 模拟支付

1. 由购物车结算、住宿预订、门票购买、路线购买等入口跳转到「收银台（模拟微信支付）」。
2. 页面展示订单号、应付金额与模拟二维码。
3. 点击「模拟扫码支付」完成支付（演示环境不产生真实扣款），成功后跳转订单页。
4. 点击「暂不支付」返回订单页，订单保持待支付状态，可稍后在订单页点击「去支付」继续。
5. 已支付的订单再次进入收银台会提示"该订单已支付"并自动返回订单页。

### 2.10 个人中心

点击顶部导航昵称下拉菜单「个人中心」进入，包含 5 个标签页：

#### 我的资料

1. 手机号只读展示；可修改昵称、头像 URL、性别（保密/男/女）、地区、简介。
2. 点击「保存资料」保存修改。
3. 普通用户可点击「申请成为商家」进入入驻申请页（见 3.1）；商家用户显示「已入驻商家」标签与「店铺信息」按钮，可修改店铺名、联系人与联系电话。
4. 「修改密码」区填写原密码与新密码（8 至 20 位，含字母和数字），点击「修改密码」。

#### 收货地址

1. 点击「新增地址」打开弹窗，填写收货人、手机号、省份、城市、区县、详细地址，可打开「默认地址」开关，点击「保存」。
2. 已有地址可点击「编辑」修改、「删除」移除；默认地址带「默认」标签。

#### 消息通知

1. 查看系统消息列表，未读消息标题加粗显示。
2. 点击「全部标为已读」一键处理。

#### 我的收藏

1. 「商品收藏」展示收藏的非遗商品，点击跳转商品详情。
2. 「游记收藏」展示收藏的游记标题，点击跳转帖子详情。

#### 我的游记

1. 查看自己发布的游记及状态标签（待审核、已驳回、已发布）。
2. 每条游记可点击「删除」并确认后移除。

## 三、商家端操作（管理后台）

### 3.1 商家入驻申请（PC 游客端发起）

1. 使用游客账号登录 PC 端，进入个人中心，点击「申请成为商家」。
2. 填写：店铺名称（如"乌东苗绣坊"）、经营模块（衣 · 非遗好物 / 食 · 餐饮美食 / 住 · 民宿住宿 / 行 · 线路订票四选一）、联系人、联系电话、营业执照号，补充材料选填。
3. 点击「提交申请」，提示"申请已提交，请等待平台审核"。
4. 页面顶部「我的申请记录」展示申请状态：审核中、已通过、已驳回（含驳回原因）。
5. 审核通过后，该账号在管理后台登录即可看到本模块的管理菜单。

### 3.2 商家登录管理后台

1. 访问 http://localhost:5174（开发）或 http://localhost:8082（容器）。
2. 使用对应商家账号登录（见 1.2 演示账号表；各模块商家密码均为 merchant123）。
3. 登录后左侧菜单仅显示本模块入口（商品管理/餐厅管理/民宿管理/票务管理），顶部显示店铺名标签与昵称；「仪表盘」展示本模块统计数据。
4. 点击右上角昵称下拉菜单「退出登录」退出。

### 3.3 衣商家：商品管理

1. 「商品管理」标签页：
   1. 搜索框按商品名搜索；状态下拉筛选上架中/已下架。
   2. 点击「新增商品」或行内「编辑」打开弹窗：填写商品名、副标题、分类（下拉选择）、主图 URL、市场价、运费、工艺介绍、详情；「SKU 规格」区点击「添加规格」逐条维护规格名、价格、库存，可删除行；「图片 URL」填写多个图片地址（英文逗号分隔）。
   3. 点击「保存」完成；列表中可「上架/下架」「删除」（删除需确认）。
2. 「库存预警」标签页：展示库存低于 10 件的商品规格，点击「调整库存」弹窗输入新库存（非负整数）。
3. 「订单管理」标签页：按状态筛选查看本店订单（订单号、内容、金额、状态、下单时间），点击「详情」弹窗查看商品明细；若订单存在退款单，弹窗中展示退款单号与状态。
4. 「评价管理」标签页：查看商品评价（星级、内容、商家回复、状态），点击「回复」填写回复内容（回显到游客端评价下方），点击「隐藏/恢复显示」控制评价展示。

### 3.4 食商家：餐厅管理

1. 「餐厅信息」标签页：维护餐厅名称、地址、营业时间（如 11:00-21:00）、餐位容量、主图 URL、餐厅介绍，点击「保存餐厅信息」。
2. 「菜品管理」标签页：点击「新增菜品」或「编辑」维护菜名、价格、图片 URL、介绍，可设置「招牌菜」与「上架」状态；行内可「删除」。
3. 「时段管理」标签页：点击「新增时段」维护时段名称（如"午餐 11:30-13:30"）、每时段可订数与启用状态；可编辑、删除。
4. 「预订管理」标签页：按订单状态筛选查看餐位预订订单（订单号、用餐日期、人数、联系人、联系电话、金额）。对已支付订单点击「确认」（确认后顾客收到通知）或「拒绝」（需填写拒绝原因，订单取消并释放余量）。
5. 「农产品」标签页：搜索、新增与编辑农产品（名称、分类、价格、规格、库存、图片 URL、产地、保质期、运费、详情），支持上架/下架。

### 3.5 住商家：民宿管理

1. 「民宿管理」标签页：点击「新增民宿」或「编辑」维护名称、地址、风格标签与设施标签（逗号分隔）、主图 URL、介绍、入住时间、退房时间、押金、含早餐、可带宠物与上架状态；行内支持上架/下架。
2. 「房型管理」标签页：顶部下拉按民宿筛选；点击「新增房型」维护所属民宿、房型名、床型、面积、可住人数、设施、价格、库存、图片 URL 与在售状态；可编辑、删除。
3. 「房态日历」标签页：
   1. 依次选择民宿与房型，表格展示未来日期每天的价格、已订、总库存与状态（可订/关闭）。
   2. 勾选一个或多个日期后点击「批量设置所选 X 天」，弹窗中设置可订状态与动态价格（留空则不改价），点击「确定」批量生效；游客端价格明细随之更新。
4. 「住宿订单」标签页：按状态筛选查看订单（订单号、入住信息、入住码、金额、状态）。
5. 「入住核验」标签页：输入顾客出示的入住码，点击「核验办理入住」，成功时展示订单号、房客与入住区间。

### 3.6 行商家：票务管理

1. 「路线套餐」标签页：点击「新增路线」或「编辑」维护路线名、天数、价格、主题、出发地、目的地、费用包含、预订须知、主图 URL、详情与上架状态；「逐日行程」区点击「添加行程日」逐日填写行程描述、景点、餐饮、住宿、交通；行内支持上架/下架。
2. 「电子票核销」标签页：输入游客出示的电子票号，点击「核销」，成功时提示核销成功并显示游客与票号。
3. 「电子票记录」标签页：按状态（未核销/已核销/已退款）筛选查看全部电子票（票号、游客、使用日期、状态、核销时间）。
4. 「票务订单」标签页：按状态筛选查看门票与路线订单（订单号、类型、内容、金额、状态）。

### 3.7 商家结算查看

1. 商家的订单在平台「财务管理」中按佣金率自动生成账单与结算单（见 4.6）。
2. 商家端不直接操作结算，结算单由平台管理员生成并确认打款。

## 四、平台管理员操作（管理后台）

### 4.1 登录与仪表盘

1. 使用平台管理员账号 13800000000 / admin123 登录管理后台。
2. 登录后默认进入「仪表盘」，展示 8 个统计卡片：注册用户、今日新增用户、订单总数、今日订单、成交总额 GMV、入驻商家、待审商家申请、浏览量 PV。
3. 下方「订单状态分布」区以标签形式展示各订单状态数量（待支付至已退款共 8 种状态）。
4. 左侧菜单共 8 项：用户管理、商家审核、订单总览、退款审批、内容审核、敏感词管理、运营管理、财务管理。

### 4.2 商家审核

1. 进入「商家审核」，顶部可切换全部/待审核/已通过/已驳回。
2. 表格展示店铺名、模块、联系人、联系电话、营业执照号与状态。
3. 对待审核申请：
   1. 点击「通过」并确认，该用户成为对应模块商家。
   2. 点击「驳回」，弹窗填写驳回原因；原因会展示在申请人 PC 端的申请记录中。

### 4.3 用户管理

1. 进入「用户管理」，可按手机号/昵称搜索，按角色（普通用户/商家/管理员）筛选。
2. 表格展示 ID、手机号、昵称、角色标签、状态与注册时间。
3. 对非管理员用户点击「禁用」（确认后该账号禁止登录）或「解禁」恢复。

### 4.4 订单总览

1. 进入「订单总览」，可组合筛选：订单状态（8 种）、订单类型（实物商品/餐位预订/住宿预订/门票/路线）、订单号搜索。
2. 表格展示订单号、类型、内容、金额、状态与下单时间；点击「查询」刷新。

### 4.5 退款审批

1. 进入「退款审批」，顶部切换全部/待审核/已通过/已驳回。
2. 表格展示退款单号、订单号、订单类型、申请人、金额、原因与状态。
3. 对待审核退款：
   1. 点击「同意退款」并填写处理备注（选填），确认后回补库存并原路退款。
   2. 点击「驳回」并填写驳回原因。
4. 处理备注与驳回原因会显示在游客订单页的退款单信息中。

### 4.6 财务管理与结算生成

1. 「账单明细」标签页：
   1. 可按商家 ID（1 衣 / 2 食 / 3 住 / 4 行）与结算状态（未结算/已结算）筛选。
   2. 每笔记录展示订单 ID、订单金额、佣金率、平台佣金、商家收入、结算状态、结算单号与记账时间。
   3. 点击「生成结算单（T+7）」：将满 T+7 周期的未结算记录按商家汇总生成结算单，弹窗确认后提示生成张数。
2. 「结算单」标签页：
   1. 按状态（待打款/已打款）筛选，展示结算单号、商家、结算金额、结算周期、状态与生成时间。
   2. 对待打款结算单点击「确认打款」，确认金额后完成打款。

### 4.7 内容审核

「内容审核」包含 3 个标签页：

#### 游记审核

1. 按状态（待审核/已过审/已驳回）筛选，按标题/内容搜索。
2. 对待审核游记点击「通过」或「驳回」（驳回需填写原因）。
3. 任意游记可点击「设为热门/取消热门」（热门帖在社区与首页展示「热门」标签）、「删除」（需确认）。

#### 评论管理

1. 表格展示评论 ID、用户、内容与状态。
2. 点击「隐藏」隐藏违规评论（游客端不可见），点击「恢复」重新展示。

#### 举报处理

1. 表格展示举报人、举报对象、原因与状态。
2. 对待处理举报点击「下架内容」（确认后下架被举报内容并记录处理说明）或「驳回举报」。

### 4.8 敏感词管理

1. 输入敏感词后点击「添加敏感词」或按回车，词条以标签形式展示。
2. 点击标签上的关闭图标并确认可删除。
3. 用户发布游记或评论时命中敏感词，内容自动进入人工审核（对应 2.7 与 4.7 的审核流程）。

### 4.9 运营管理

「运营管理」包含 4 个标签页，内容发布后即时生效于 PC 游客端：

#### 轮播图

1. 点击「新增轮播图」弹窗填写标题、图片 URL、跳转链接、排序，状态开关控制上架；点击「保存」。
2. 行内可「编辑」「上架/下架」「删除」；上架中的轮播图在首页顶部轮播展示。

#### 活动横幅

1. 点击「新增活动」填写标题、图片 URL、跳转链接、开始时间、结束时间与上架状态。
2. 行内可「编辑」「删除」；上架中的活动横幅展示在首页公告下方。

#### 公告

1. 点击「新增公告」填写标题与内容，状态开关控制是否展示。
2. 行内可「编辑」「删除」；展示中的公告以提示条形式显示在首页。

#### 热搜词

1. 输入热词与排序值，点击「保存热词」新增。
2. 行内可「编辑」（回填到输入区）与「删除」。

## 五、常见问题

### 5.1 短信验证码

1. 注册时点击「获取验证码」后，测试环境不发送真实短信，固定填写 123456 即可通过校验。
2. 「获取验证码」按钮有 60 秒倒计时，倒计时内不能重复获取；如需重试请等待倒计时结束。

### 5.2 模拟支付说明

1. 平台未接入真实支付渠道，收银台展示的二维码为演示图案，不产生真实扣款。
2. 点击「模拟扫码支付」即完成支付，订单状态变为已支付；不点击按钮直接离开则订单保持待支付，可在订单页点击「去支付」再次进入收银台。
3. 已支付订单重复进入收银台会被拦截并提示"该订单已支付"。

### 5.3 退款流程

1. 游客对已支付、已确认、进行中的订单点击「申请退款」并填写原因。
2. 退款申请提交后订单进入退款中状态，由平台管理员在「退款审批」中同意或驳回。
3. 同意后退款金额原路返回（演示环境无真实资金流转），库存回补；驳回时游客可在订单页看到处理备注。

### 5.4 餐位预订被拒绝

餐位预订提交后由食商家在管理后台确认；若商家「拒绝」，订单取消并释放余量，请改选其他时段或日期重新预订。

### 5.5 门票/住宿/电子票核销

1. 门票与路线电子票由行商家在管理后台「电子票核销」输入票号核销；住宿由住商家在「入住核验」输入入住码核销。
2. 游客可在「我的电子票」查看核销状态；住宿订单的入住核销码显示在订单页住宿扩展信息中（已支付/已确认状态可见）。

### 5.6 内容审核

1. 发布游记或评论命中敏感词后不会立即展示，提示"已提交人工审核"。
2. 由平台管理员在「内容审核」中通过或驳回；驳回的游记在游客「我的游记」中显示「已驳回」标签。

### 5.7 权限与访问限制

1. PC 游客端购物车、订单、支付、个人中心、发布游记等页面需登录后访问，未登录会自动跳转登录页并在登录后返回原页面。
2. 管理后台按角色显示菜单：平台管理员可见全部管理菜单；商家仅可见本模块菜单；商家访问平台管理员页面或访问其他模块页面会被重定向回仪表盘。

### 5.8 常见报错处理

1. 提示"请先登录"：先完成登录再操作。
2. 门票提示"当日余票不足"：减少购买数量或更换使用日期。
3. 购物车商品标记"库存不足"：调整数量或等待商家补货。
4. 提示"库存不足/操作失败"等由服务端返回的错误：请确认后端服务与数据库正常启动，必要时重新登录。
