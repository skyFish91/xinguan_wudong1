## 5. 实践收获

1. **AI 不是替代，是杠杆**：Claude Code 把"写代码"的成本大幅降低后，人的精力可以放到架构决策、需求确认、验收标准上——ADR、Skill 规范、测试用例这些"人把关"的东西反而成了质量关键
2. **规范沉淀的复利**：把命名/响应格式/防超卖约定写进 Skill 后，后续模块开发零风格漂移，联调期几乎无接口对不上的问题
3. **测试的价值超出"覆盖率"**：3 个真实缺陷（路线下单必失败、审核发帖必报错、路线列表缓存串数据）都是测试暴露的，演示前被拦截
4. **环境工程的坑真实存在**：Docker 镜像拉取受网络环境影响（VPN 劫持），工程文件写得再好也要考虑部署环境的现实
5. **文档与代码同步是硬约束**：契约（DDL/实体/Swagger）三处不同步会直接变成运行时缺陷（published_at 约束问题就是例子）

## 6. 结语

3 天完成一个"可部署、可测试、可演示、可答辩"的完整文旅平台，验证了"AI 协作 + 规范沉淀 + 测试兜底"的方法论。本项目所有产出（代码/文档/测试/部署）均可复现：`docker compose up -d --build` 一条命令即可跑通全系统。
