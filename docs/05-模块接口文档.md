# 模块接口文档

> 对应课程第 3 天（9 月 9 日）核心产出

## 1. 总体说明

本文档汇总乌东文旅平台后端全部 HTTP 接口，事实来源为 `server/src/module/` 下各模块 controller 与 dto 的实际代码（Swagger 注解 `@ApiOperation summary` 为接口用途的直接来源），错误码来源为 `server/src/common/constants.ts`。

### 1.1 接口前缀与响应格式

- 接口前缀：全部接口以 `/api` 开头（各 controller 通过 `@Controller('/api/xxx')` 声明）。
- 响应格式：统一响应约定为 `{ code, message, data }`，`code = 0` 表示成功。当前实现中：成功时直接返回业务数据本身（前端以"code 为数字且非 0"判定业务错误）；异常由全局异常过滤器统一转为 `{ code, message, data: null }`，其中 1001 映射 HTTP 401、1004 映射 403、3005 映射 404，其余 HTTP 200。
- 分页格式：列表接口统一返回 `{ list, total, page, pageSize }`，page 从 1 起，默认 pageSize 为 10 或 12（以各接口声明为准）。

### 1.2 错误码体系

| 分段 | 错误码 | 含义 | 触发场景 |
|------|--------|------|----------|
| 1xxx 认证 | 1001 | 未登录 | @Auth 接口未携带有效 token（HTTP 401） |
| | 1002 | token 过期 | refreshToken 校验失败，需重新登录 |
| | 1003 | 登录失败 | 手机号或密码错误 |
| | 1004 | 无权限 | 角色不满足 @Auth 要求（HTTP 403） |
| 2xxx 参数 | 2001 | 参数错误 | DTO 校验失败、参数缺失或格式错误 |
| 3xxx 业务 | 3001 | 业务失败 | 通用业务规则不满足 |
| | 3002 | 库存不足 | SKU/农产品/房态/票务/餐位库存不足 |
| | 3003 | 订单状态错误 | 当前订单状态不允许该操作 |
| | 3004 | 内容敏感 | 敏感词命中（发布内容自动转人工审核） |
| | 3005 | 未找到 | 资源不存在（HTTP 404） |
| 5xxx 系统 | 5001 | 系统错误 | 未捕获异常 |

### 1.3 鉴权方式

- JWT 双 token：登录返回 `accessToken`（2 小时）+ `refreshToken`（7 天），请求头携带 `Authorization: Bearer <accessToken>`；accessToken 过期后用 refreshToken 换新。
- AuthGuard 全局中间件解析 token 写入 `ctx.currentUser`（userId/role/merchantId/merchantType），并按方法上 `@Auth(...)` 装饰器元数据校验角色。
- 装饰器含义：`@Auth()` 任意登录用户；`@Auth('merchant')` 仅商家；`@Auth('admin')` 仅管理员；`@Auth('merchant', 'admin')` 商家或管理员。未标注即公开接口。

### 1.4 订单状态与订单类型

| 订单状态 | 值 | 说明 | 订单类型 | 值 |
|----------|-----|------|----------|-----|
| 待支付 | 0 | 下单后初始状态 | 商品 | goods |
| 已支付 | 1 | 待商家确认 | 餐位预订 | meal |
| 已确认 | 2 | 商家已确认 | 住宿预订 | hotel |

| 已取消 | 5 | 终态 | | |
| 退款中 | 6 | 已申请退款 | | |
| 已退款 | 7 | 终态 | | |
