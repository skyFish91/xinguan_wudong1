## 5. 依赖安装验证步骤

```bash
# 1. 验证 MySQL
mysql -uroot -p -e "SELECT VERSION();"        # 8.0.41

# 2. 验证 Redis（Docker）
docker run -d --name wudong-redis -p 6379:6379 redis:7-alpine

# 3. 验证后端
cd server && npm install && npm run dev       # http://localhost:7001

# 4. 验证前端
cd web && npm install && npm run dev          # http://localhost:5173
cd admin && npm install && npm run dev        # http://localhost:5174
```

## 6. 网络与镜像

| 检查项 | 说明 |
|--------|------|
| npm 镜像 | 默认源即可，若慢可切 npmmirror |
| Docker 镜像 | redis:7-alpine、node:20-alpine 等 |
| 外网访问 | 下载依赖需要网络 |

## 7. 风险与应对

| 风险 | 应对 |
|------|------|
| Docker Desktop 冷启动慢 | 提前启动，或用本机 MySQL 替代容器方案 |
| npm 安装依赖超时 | 切换 npmmirror 镜像源 |
| 微信支付无法真实接入 | 按需求书使用模拟支付（演示可用） |
