## 一、项目定位

"乌东文旅'衣食住行'综合服务平台"：面向贵州黔东南乌东村文旅场景，为游客提供衣（非遗商品）、食（餐饮美食）、住（住宿预订）、行（线路订票）、社区（照片分享）五位一体的一站式服务，同时为商家与平台提供运营管理能力。课程小组项目，模块化单体架构，全流程可复现。

## 三、如何运行

**方式一：开发环境（本机日常使用）**

1. 双击项目根目录 `start-dev.bat`，自动拉起 MySQL、Redis（Docker 容器）、后端（7001）、前端（5173）
2. 浏览器打开 `http://localhost:5173/`

**方式二：容器部署（演示/交付环境）**

```bash
cd deploy
docker compose up -d --build
```

- 游客端：`http://localhost:8081/`
- 管理后台：`http://localhost:8082/`
- 同一网络的其他电脑：`http://本机IP:8081/`（需先运行一次 `allow-firewall.bat`）

**测试与构建**

```bash
cd server && npm test      # 227 用例，语句覆盖率 80.74%
cd server && npm run build # TS 编译构建
```
