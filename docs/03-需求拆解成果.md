## 3. 公共能力拆解（P）

### P1 用户体系
- [x] 注册：手机号 + 验证码（开发期验证码固定 123456，文档说明模拟）
- [x] 登录：手机号 + 密码（JWT 双 token：access 2h + refresh 7d）
- [x] 密码规则：8-20 位，至少含字母与数字（bcrypt 加密存储）
- [x] 个人中心：资料、订单（按类型 Tab）、收藏聚合、相册、评价、收货地址、消息、设置
- [x] 商家入驻申请：提交资质 → 管理员审核 → 开通商家权限

### P2 统一购物车
- [x] 衣（商品）+ 食（农产品）共用；预订类（民宿/餐位/门票/路线）不进入购物车
- [x] 增删改、规格切换、库存校验、失效提醒

### P3 统一订单中心
- [x] 5 类订单：商品、餐位预订、住宿预订、门票、路线
- [x] 状态机：待支付 → 已支付/待确认 → 已确认 → 进行中 → 已完成；可取消/退款分支
- [x] 操作：支付、取消、退款申请、确认收货

### P4 支付
- [x] 模拟微信支付：下单生成"支付二维码"页面，点击"模拟扫码支付"完成支付
- [x] 支付回调状态更新、退款原路返回（模拟）

### P5 文件上传
- [x] 图片 jpg/png/webp ≤5MB、视频 mp4 ≤100MB 且 ≤60s
- [x] 本地磁盘存储 + 静态文件服务（需求书 4.3 要求"上传到本地磁盘"）
- [x] 敏感词过滤（关键词库 + 命中进入待审核）

### P6 消息通知
- [x] 站内消息：系统公告、订单状态、互动消息，统一消息中心

### P7 搜索
- [x] 商品/餐厅/民宿/线路/游记关键词搜索，排序（热度/价格/评分/时间），搜索历史

## 4. 模块一 衣-非遗商品（M1）

### 数据实体
分类、商品、SKU、商品图片、评价、收藏（6 表）

### 前台功能
| 编号 | 功能 | 要点 |
|------|------|------|
| M1-1 | 分类浏览 | 一级（银饰/蜡染/刺绣/服饰/其他）+二级 |
| M1-2 | 商品列表 | 分类/价格/销量/评分筛选，分页 |
| M1-3 | 商品搜索 | 关键词 + 历史 + 热搜 |
| M1-4 | 商品详情 | 主图轮播、SKU 规格、工艺介绍、传承人故事、评价列表、富文本 |
| M1-5 | 加购/立即购买 | 规格选择校验库存 |
| M1-6 | 收藏 | 收藏/取消 |
| M1-7 | 评价 | 已购可评（文字+图+评分），30 天内可追评，商家回复 |

### 后台功能
分类管理、商品管理（上下架/批量）、库存管理（预警<10）、订单管理（发货/退款审核）、评价管理、数据统计（销售额/热销TOP10）

### 业务规则
运费模板、7 天无理由退换、库存 0 不可下单

## 5. 模块二 食-餐饮美食（M2）

### 数据实体
餐厅、菜品、餐位时段、餐位预订订单、农产品分类、农产品商品、评价（7 表）

### 前台功能
| 编号 | 功能 | 要点 |
|------|------|------|
| M2-1 | 餐厅列表 | 距离/评分/价格排序 |
| M2-2 | 餐厅详情 | 菜品、营业时间、位置、评价 |
| M2-3 | 餐位预订 | 日期→时段→人数→姓名电话→提交 |
| M2-4 | 我的餐位预订 | 查看/取消（24h 前免费，24h 内扣 50%） |
| M2-5 | 农产品 | 分类（茶叶/腊肉/米酒/酸食）、详情（产地溯源/保质期）、加购 |

### 后台功能
餐厅管理、时段管理（最大预订数）、预订管理（确认/拒绝）、农产品分类与商品管理、订单/评价管理、数据统计

### 业务规则
餐位提前 2 小时预订、农产品独立运费模板、原产地溯源

## 6. 模块三 住-住宿预订（M3）

### 数据实体
民宿、房型、房态日历、入住须知、评价、收藏（6 表）

### 前台功能
| 编号 | 功能 | 要点 |
|------|------|------|
| M3-1 | 民宿搜索 | 入住/离店日期 + 人数 |
| M3-2 | 民宿列表 | 价格/风格/设施/评分筛选 |
| M3-3 | 民宿详情 | 房型、设施、地图、须知、评价 |
| M3-4 | 房态日历 | 未来 30 天可订情况，动态定价 |
| M3-5 | 预订 | 房型→日期→入住人（含身份证）→预付 |
| M3-6 | 入住码 | 订单生成入住码供到店核验 |

### 后台功能
民宿管理、房型管理、房态日历管理（90 天视图/批量设房态/动态定价）、订单管理（确认/改期/退款审核）、评价管理、数据统计（入住率/平均房价）

### 业务规则
预付房费；取消：3 天前免费、1-3 天扣 30%、当天不退；评价离店后 30 天内

## 7. 模块四 行-线路订票（M4）

### 数据实体
景区、票种、路线套餐、路线行程、电子票、交通攻略、评价（7 表）

### 前台功能
| 编号 | 功能 | 要点 |
|------|------|------|
| M4-1 | 门票列表 | 景区 + 票种（成人/儿童/学生/家庭套票） |
| M4-2 | 门票购买 | 票种→日期→数量→游客信息→支付 |
| M4-3 | 路线套餐 | 一日/两日/多日游，主题筛选（亲子/摄影/研学/节庆） |
| M4-4 | 路线详情 | 每日行程（景点/用餐/住宿/交通）、包含项目 |
| M4-5 | 交通攻略 | 按出发地（贵阳/凯里/广州） |
| M4-6 | 电子票 | 订单生成二维码，后台扫码核销 |
| M4-7 | 退票 | 24h 前可退扣 10%，24h 内不可退 |

### 后台功能
景区/票种/路线套餐/交通攻略管理、电子票核销（扫码+手输票号）、订单管理、数据统计

### 业务规则
门票按日期分库存、路线提前 1 天预订、电子票当日有效

## 8. 模块五 社区-照片分享（M5）

### 数据实体
游记、评论、话题、关注关系、收藏、点赞、举报（7 表）

### 前台功能
| 编号 | 功能 | 要点 |
|------|------|------|
| M5-1 | 信息流 | 推荐/最新排序，图片瀑布流 |
| M5-2 | 发布游记 | 图 ≤9 张或视频 ≤60s + 话题 + 关联地点 |
| M5-3 | 游记详情 | 轮播、话题、关联地点、点赞/评论/收藏 |
| M5-4 | 评论 | 一级 + 二级回复 |
| M5-5 | 话题页 | 话题详情 + 下游记 |
| M5-6 | 关注 | 关注/取关、关注列表、粉丝列表 |
| M5-7 | 个人主页 | 游记列表、获赞/关注/粉丝数 |
| M5-8 | 举报 | 游记/评论举报 |

### 后台功能
内容审核（通过/拒绝含原因）、游记管理（下架/删除）、评论管理（敏感过滤）、话题管理、举报处理、热门推荐、数据统计

### 业务规则
游记 ≤5000 字、日限 10 篇、评论 ≤500 字、敏感词过滤、命中 3 次禁言 24h

## 10. 非功能需求拆解

| 编号 | 需求 | 拆解动作 |

## 11. 拆解结论与风险

1. 接口总量约 168 个，P0 模块优先（公共 + M1-M4 + M6），M5 紧随
2. 难点：房态日历并发库存、电子票核销、订单状态机、内容审核流程
3. 模拟方案：短信验证码固定值、微信支付二维码模拟页、地图用静态图+文字地址
4. 里程碑：9 月 9 日脚手架+M1，9 月 10 日全模块+Redis，9 月 11 日 Docker+测试，9 月 12 日文档+路演
